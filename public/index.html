Deploy Aplikasi Statis ke Cloudflare

Proyek ini dikembangkan untuk mempelajari alur deployment modern dari source code Git di GitHub hingga menjadi website publik aktif di *.workers.dev.

Uji Interaktivitas JavaScript

Klik tombol di bawah ini untuk memverifikasi bahwa skrip client-side berjalan sempurna setelah deployment.

Informasi Deployment

  • Platform: Cloudflare Workers (Static Assets)
  • Folder Assets: ./public
  • Config File: wrangler.jsonc
  • Trigger Deploy: Git Push (Branch main)

Checklist Evidence Deployment

  • ✓ Repository GitHub Publik tersedia
  • ✓ File wrangler.jsonc terkonfigurasi pada root repo
  • ✓ Asset statis berada di dalam folder ./public
  • ✓ Deployment aktif dan dapat diakses publik melalui *.workers.dev
