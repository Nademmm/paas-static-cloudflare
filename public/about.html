Tentang Praktikum Minggu 4

Modul praktikum mandiri ini berfokus pada alur kerja Continuous Deployment menggunakan Git integration pada Cloudflare Workers Builds.

Konsep Utama

Cloudflare Workers memanfaatkan jaringan global edge server untuk menyajikan Static Assets tanpa memerlukan server fisik atau VM dedicated. Setiap kali perubahan di-push ke branch main di GitHub, Cloudflare secara otomatis mendeteksi commit terbaru dan menjalankan deployment ulang.
